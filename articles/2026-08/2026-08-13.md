# AI 日报 | 2026-08-13

今日主线是「开源权重 + Agent 工具链」：Qwen 开放 Qwen3.8-2.4T-A95B 权重，Meta Muse Glimmer 发布并获 transformers 支持，Claude Code 与 QwenCloud 同日更新。

## 今日必看
- Qwen 开放 Qwen3.8-2.4T-A95B 开源权重（2026-08-08 · `官方确认` · 近7日重要更新）：2.4T 总参数 / 95B 激活的 MoE 模型，原生 26 万上下文、可扩展至约 100 万 token；纯文本、强制思考模式；官方 API 版 Qwen3.8-Max 额外提供视觉输入、1M 上下文与内置工具。[来源](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)

## 最新模型发布
- Meta 发布 Muse Glimmer 多模态模型（2026-08-10 · `官方确认` · 近7日重要更新）：专为 Agent 场景设计，从 Muse 蒸馏至 30B（2B 视觉编码器 + 28B 文本解码器），Apache 2.0 许可、可本地部署；transformers v5.15.0 已加入支持。[来源](https://github.com/huggingface/transformers/releases/tag/v5.15.0)
- QwenCloud 上线 qwen3.7-text-embedding（2026-08-11 · `官方确认`）：基于 Qwen3.7 的多语言文本向量模型，官方称 MTEB 多语言、中英与代码检索任务较 text-embedding-v4 提升约 20%，支持 256–2560 自定义向量维度。[来源](https://docs.qwencloud.com/changelog/models)

## Agent 与开发工具
- Claude Code v2.1.229 发布（2026-08-12 · `官方确认`）：新增 claude remote-control --continue 恢复最近远程会话、自托管 runner 的 hook 支持、gateway SSE keepalive（避免 Vertex/Bedrock 长时间思考断连）、插件市场 command 源；修复流式输出重复、窄终端崩溃、Windows 长路径崩溃等问题。[来源](https://github.com/anthropics/claude-code/releases/tag/v2.1.229)
