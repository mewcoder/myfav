# AI 日报 | 2026-08-14

今日主线是「模型正式版与 Agent 原生能力」：DeepSeek-V4-Pro-0813 官方权重发布、Google 发布 Gemini 3.7 Flash、Qwen3.8 开放 API，另有 Agent 原生视频表征论文。

## 今日必看
- DeepSeek 发布 DeepSeek-V4-Pro-0813 正式版权重（2026-08-13 · `官方确认`）：取代 Preview 版本，增强 agentic 能力并附 DSpark 投机解码模块；官方基准 Terminal-Bench 2.1 达 87.9、Cybergym 83.3、DeepSWE 62.7（Preview 分别为 72.1 / 52.7 / 12.8）；MIT 许可，vLLM 与 SGLang 已支持。[来源](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-0813)

## 最新模型发布
- Google DeepMind 发布 Gemini 3.7 Flash（2026-08-13 · `官方确认`）：定位面向 coding 与 Agent 的最强 workhorse 模型；FrontierCode 1.1 Main 达 43.6%（3.6 Flash 为 34.4%）、DeepSWE v1.1 达 65.3%（49.0%）；介绍价 $0.75/M 输入、$3.75/M 输出（约 3.6 Flash 首发价一半）；Gemini Spark 已切换至该模型。[来源](https://deepmind.google/blog/introducing-gemini-3-7-flash/)
- QwenCloud 上线 qwen3.8-2.4t-a95b API（2026-08-13 · `官方确认`）：开源旗舰系列的托管 API，稀疏 MoE 架构、2.4T 总参数 / 约 95B 激活，支持 100 万 token 上下文，默认思考模式，官方称 coding 与长程 Agent 任务显著改进。[来源](https://docs.qwencloud.com/changelog/models)

## 研究雷达
- AVA-Encoder：面向 Agent 的视频表征学习框架（2026-08-12 · `论文原文`）：把视频编码为知识图谱再重建回视频，供 Agent 查询与编辑；报告较最强外部基线提升 20.7 个百分点，伪训练策略在系统提示 token 上少用 74.3%。[来源](https://arxiv.org/abs/2608.12313v1)
